# Instagram 主页媒体下载与统一顶部进度

`.12` 改用 `combined` 补丁包，同时提供 NewX 与 Instagram 补丁，保留已有 X 功能，不包含旧版 Twitter 补丁。本轮验证目标为 **Instagram 439.0.0.37.89 / 384510827，arm64-v8a**；X 目标仍为 **12.34.0-prod.01 / 312340001，arm64-v8a**，本轮未复验 X。

在 Morphe 刷新补丁源到 `.12`，选择对应应用的原版 APK / APKM 并重新载入默认选择。Instagram 保留 `Download media` 和 `Download all profile media`。不要沿用另一应用或旧版本的补丁选择。

Instagram 使用方法：先选择保存文件夹并授予权限，打开目标主页的 **帖子网格**，**手动刷新一次并等待网络加载完成**，再打开 **更多资料选项 → 下载此主页的全部图片和视频**。下载器复用原生分页，逐个保存到主页用户名子文件夹，每页文件完成后等待 30 秒再加载下一页，请保持主页在前台。

- 下载范围为当前登录账号可通过主页帖子网格访问的图片、视频及轮播。不含快拍、精选、被标记页和未放入帖子网格的独立 Reels 内容。
- 顶部卡片显示当前文件百分比、进度条、大小、速度、完整文件名和已保存/已发现数量；总量未知时显示动态进度条，结果按任务排队。系统通知栏进度保留。通过 `DownloadUtils` 发起的单帖、头像、语音、私信媒体等下载也使用同一串行队列。
- 可在卡片上暂停；离开主页、进入后台、分页失败、游标重复或缺失、分页停滞时也会暂停，不自动循环重试。返回帖子网格并手动刷新后，从同一菜单继续。按登录账号、目标用户与媒体编号保存历史，已保存文件仍存在时跳过；未完成的单个文件需重新下载。
- 媒体文件 HTTP 401/403/429 至少冷却 15 分钟，并采用可解析的更长 `Retry-After`；原生分页仅能读取 HTTP 状态，401/403/429 同样触发至少 15 分钟冷却，不能读取该路径的 `Retry-After`。冷却结束后需手动继续。原生登录、验证与访问限制保留，不保证零风控提示。

本次补齐三项边界保护：后续原生分页前重新检查共享冷却；准备媒体、轮播与保存历史时及时响应暂停；任务结束后丢弃晚到的进度回调，避免顶部卡片重新出现。
