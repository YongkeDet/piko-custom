# Instagram 451 启动闪退修复

`.14` 修复 Instagram **451.0.0.53.80 / 385713073 / arm64-v8a** 在启动后被 Android 校验器拒绝的问题。用户报告设备为小米、Android 16 / SDK 36，补丁版本 `.13`。

原因位于 `Filter stories`：旧实现按文字匹配顺序选择附近的条件跳转，误把字段名比较的整数结果当成快拍对象；插入的外部标签又指向 `move-result-object`，生成日志中的 `0x146 → 0x14b` 无效跳转。已在同一份 `.13` 输出中复现，原版安装包没有该问题。

修正从明确的 `tray` 字段、原生数组标记检查和 ArrayList 分配定位列表循环，再校验解析返回对象、空值检查、列表添加及同一个循环继续目标。过滤发生在已解析对象的原生空值检查之前，保留原检查和循环，使用类型化指令插入及明确的标签迁移策略；空对象直接回到原生检查。

在 Morphe 刷新补丁源到 **3.10.0-custom-newx.14**，选择原版 **451.0.0.53.80 APKM**，重新载入 Instagram 默认选择，保留 `Filter stories`、`Download media` 和 `Download all profile media` 后重新修补。使用原来的 Morphe 签名覆盖安装，保留现有应用数据。安装后先正常启动，再检查主页批量下载、顶部进度、暂停和继续。

验证：源码 `64c3e563349a46f51f5444e17f1795caceb8caa6` 的 [CI 39131182384](https://github.com/YongkeDet/piko/actions/runs/39131182384) 成功，377 项测试通过；新增回归覆盖字段顺序、向后的字段循环、对象输入、原生循环继续目标、指令跳转，以及错误/歧义形态拒绝。451 默认 60 项修补零失败并重建成功，254 项最终代码和资源检查通过。全包扫描 831824 个方法、2746435 个分支目标、3113626 条结果读取指令，孤立结果读取及跳入结果读取的错误均为零。MPP SHA-256：`c8b8b790540bdb1224029e79f4ae1fc9edf8c4a59e494480fa76edf22ec34fbc`。

按用户要求，本轮只修补验证 451，没有重新验证 439 或 X。没有安装、启动或控制手机；小米 Android 16 上的实际重新启动仍待用户复验。主页下载等原有功能保留；451 高级 MetaConfig 名称映射仍暂无上游文件。
