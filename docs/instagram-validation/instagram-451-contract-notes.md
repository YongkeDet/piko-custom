# Instagram 439 / 451 原生契约适配依据

目标为原版 `com.instagram.android`：439.0.0.37.89 / 384510827 和 451.0.0.53.80 / 385713073，均为 arm64-v8a。输入、补丁包和输出的散列、精确源码与 CI 来源见 [451 升级验证记录](validated-instagram-upgrade-2026-10-18.json)。版本列表只声明兼容性；实际适配依据 APK 的类型、调用和数据流，不按版本号分支。

| 变化 | 定位与约束 |
| --- | --- |
| 设置开关样式由静态标志改为实例标志 | 从构造、绘制与设置选中状态共同读取的布尔字段推导存储形态。保留原生值，并统一经过已有的偏好样式策略。 |
| 视频模型与用户映射改为接口或静态映射器 | 从原生接口和序列化器解析真实类型；扩展只接收 Object，通过修补时生成的直接调用桥读取值，避免新反射与不稳定类型签名。 |
| R8 提取文字常量 | 只接受完整、无副作用、每个分支直接返回文字的静态整数开关表；校验调用前的常量和参数寄存器。用于推荐内容、浏览器与保存权限入口。 |
| 网络请求入口变为委托包装 | 从原生网络入口沿同形态的直接委托找到 URI 读取，要求请求参数类型与 URI 所属者一致；保留原生请求、鉴权与网络策略。 |
| Reels 菜单局部变量布局变化 | 在原生菜单构造器初始化完成后插入，使用已证实的参数与空闲寄存器，避免依赖某个列表读取位置。 |
| 推荐用户判定变为持有账号的实例方法 | 保留原生判定的帧、分支和调用，只把唯一的 UserSession 字段读取替换为传入的同一账号；扩展不重新实现判定策略。 |
| 快拍标题栏拆入工具栏子持有者 | 原标题栏入口存在时保留原路径；否则使用带明确工具栏跟踪文字的外层绑定方法。两种入口均要求唯一账号、ReelItem、reel 参数及结构匹配的根视图持有者。 |
| 标准快拍进度更新移入辅助类 | 仍从“媒体消费回调 + 原生分段进度条读取”定位标准回调，保留原有直接 setProgress 路径；分别捕获提示、标准和紧凑三种持有者。根视图从构造参数写入推导，可沿父类查找。 |
| 快拍已读媒体改为类型化包装 | 从原生消费路径推导空列表、模式编号、键、元数据构造器、媒体包装器和聚合调用；生成直接调用适配器，保留账号、媒体、待发送状态和所属用户参数。 |
| 请求调度改为接收基类 | 校验请求构造结果可赋值给原生调度参数，并复用同一请求与管理器的寄存器数据流；不把不同类型强行当成相同类型。 |
| 快拍请求由两种实现收敛为一种 | 只接受工厂实际返回的一至两种已证实的原生实现，分别读取其真实成功结果。只有存在第二种实现时才要求对应观察器。 |
| 故事菜单合并、播放器存在两种后端 | 合并去重菜单入口，避免重复插入；从原生接口推导绝对定位和恢复播放，校验当前故事身份，并保留原来的图片计时器重启与旧版播放路径。 |

默认补丁必须全部成功并完成 APK 重建，失败不能以静默跳过方式发布。最终检查还覆盖直接模型桥、样式读取、故事持有者捕获、会话判定适配器、媒体包装适配器，以及已有的主页分页、顶部进度、暂停和拒绝冷却。

验证不包含手机实际登录、联网、下载或界面试用。测试 APK 未签名；安装须由 Morphe 沿用用户原签名完成。上游暂无 451 的高级 MetaConfig ID/名称映射文件；不使用其他版本映射代替，主页下载不依赖该映射。combined 包保留 NewX 代码，本轮没有重新验证 X 安装包。
